Rules

  • Saari 12 ek page pe mat daalo. Page slow hoga. 2–3 chuno: hero + social proof + CTA se shuru karo.
  • Mobile pe test karo (Chrome DevTools → device mode + real phone).
  • PageSpeed Insights se speed check karo; animation ke baad bhi score theek rehna chahiye.
  • “Reduced motion” setting wale users ke liye animations off/soft honi chahiye (base line mein already hai).
